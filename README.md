# 신은 죽었다. 우리가 죽였다.

인간의 기도로 타락한 신의 시체가 남아 있는 예배당을 탐색하는 1인칭 3D 아날로그 공포게임입니다.

1998년 11월 3일. 신의 사망이 확인된 지 사흘째, 시체는 여전히 기도에 응답하고 있습니다. 세 봉인을 찾아 제단의 의식을 완성하고 들어온 문으로 돌아가세요.

## 실행

현재 저장소에는 플레이 가능한 Godot 프로젝트와 검증 코드가 포함되어 있습니다. Godot 4.7.1에서 `project.godot`을 열고 F6 대신 F5로 프로젝트를 실행하세요. Windows 10/11, 64비트, OpenGL 3.3 호환 그래픽 환경을 대상으로 제작했습니다.

Windows 실행 파일은 아직 배포하지 않았습니다. 아래 내보내기 명령으로 `builds/Windows/GodIsDead.exe`를 만들면 Godot 설치 없이 실행할 수 있습니다. 빌드 결과물과 임시 검증 화면은 Git에서 제외합니다.

## 살아남기

- 벽을 따라 촛불과 봉인을 찾으세요. 봉인 세 개는 서로 다른 위치에 있습니다.
- **종이 울리면 F로 손전등을 끄고 Ctrl을 계속 누르세요.** 기도가 끝났다는 메시지가 나올 때까지 기다리세요.
- 손전등 배터리는 불을 끄면 회복됩니다. 달리기 체력도 쉬면 회복됩니다.
- 세 봉인을 찾은 뒤 중앙 제단으로 가서 E를 6초 동안 누르세요.
- 의식이 끝나면 처음 들어온 붉은 문으로 돌아가 E를 누르세요. 뒤를 보면 추격자가 빨라집니다.
- 기록을 읽거나 일시정지한 동안에는 위험과 자원이 멈춥니다. 창이 비활성화되어도 자동으로 일시정지됩니다.

밝기, 소리, 마우스 감도와 VHS 화면 강도는 메뉴에서 조절할 수 있습니다. 어두운 장면, 불길한 소리, 화면 흔들림과 갑작스러운 공포 연출이 있습니다. 헤드폰을 권장합니다.

## 프로젝트

Godot 4.7.1 / Compatibility 렌더러. `project.godot`을 열어 수정할 수 있습니다. 건축, 신의 형상, 재질, VHS 후처리, 효과음과 음악은 코드로 생성됩니다. 시스템의 한국어 글꼴을 사용하며 글꼴 파일을 별도로 재배포하지 않습니다. 서버 연결, 계정, 마이크 접근, 분석 수집은 없습니다. 설정만 로컬 Godot 사용자 데이터 폴더에 저장됩니다.

주요 파일: `scripts/main.gd` (플레이와 상태), `scripts/world.gd` (공간과 형상), `scripts/hud.gd` (화면과 메뉴), `scripts/audio_director.gd` (오디오), `shaders/vhs.gdshader` (후처리).

## 개발 검증

```powershell
godot --headless --editor --path . --import --quit
godot --headless --path . --script res://tests/gameplay_test.gd
godot --path . -- --qa
godot --headless --path . --export-release "Windows Desktop" builds/Windows/GodIsDead.exe
```

`--qa`는 제작용 명시적 검증 모드로, 기록 회수·기도 생존과 실패·의식·탈출·재시작을 실행하고 `qa/`에 실제 게임 화면을 저장합니다. 일반 실행에서는 검증 동작을 수행하지 않습니다.

현재 검증 결과: 실제 충돌을 적용해 127.5m를 이동하며 세 봉인과 탈출 경로를 확인했고, 진행·일시정지·재시작을 포함한 통합 검사에서 실패가 없었습니다. 실제 렌더링으로 기록, 기도 생존과 사망, 의식, 승리와 재시작도 확인했습니다. 후속 작업으로 탈출 직후 자막 배치와 Windows 배포 패키징이 남아 있습니다.
